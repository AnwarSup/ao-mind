Core Features

Four Agents, One Framework

Each agent is purpose-built for a specific task in the AO ecosystem, using the best model for the job.

🎮
MiMo-V2.5-Pro

Game Analyzer

Real-time game state analysis for Chess, Pacman, 4 Cards & all Ctrl Play games. Generates post-game reports stored permanently on Arweave.

1.4M tokens/day
150+ sessions/day
const result = await analyzer.analyze({
  game: 'chess',
  state: 'rnbq...',
  playerLevel: 'intermediate'
})
// bestMove: 'd6', confidence: 91%

MiMo + Deepseek

Contract Auditor

Audits Lua smart contracts on AO processes. Detects access control flaws, reentrancy, missing sender verification, and logic errors before deployment.

1.1M tokens/day
CRITICAL→LOW severity
const report = await auditor.audit(luaCode, {
  processId: 'AO_PROC...',
  strictMode: true
})
// severity: HIGH, issues: 3

Get Started

Up in 60 Seconds

01

Clone & Install

git clone https://github.com/AnwarSup/ao-mind.git
cd ao-mind
npm install
02

Configure API Keys

cp .env.example .env
# Add your keys:
MIMO_API_KEY=your_mimo_key
CLAUDE_API_KEY=your_claude_key
ARWEAVE_WALLET_PATH=./wallet.json
03

Run the Agents

# Run all agents
npm run agents

# Or run individual examples
node examples/analyze-game.js
node examples/audit-contract.js
node examples/generate-content.js
