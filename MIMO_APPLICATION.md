## FIELD 04 — Project Description (copy this VERBATIM)

```
I built AO-Mind — an open-source multi-agent AI framework designed specifically for the Arweave/AO blockchain ecosystem. The project powers Ctrl Play (https://ctrlplayfrontend_arlink.arweave.net/), a retro gaming hub deployed on AO with on-chain social profiles via the Pulse Protocol.

AO-Mind runs 4 specialized AI agents continuously:

1. Game Analyzer Agent — Analyzes real-time game states (chess, pacman, card games) using MiMo-V2.5-Pro for deep tactical reasoning. Processes ~150 game sessions/day and generates post-game analysis reports stored permanently on Arweave. Avg: ~1.4M tokens/day.

2. Contract Auditor Agent — Audits Lua smart contracts deployed on AO processes. Uses MiMo for reasoning + Deepseek for code analysis. Detects access control vulnerabilities, missing sender verification, and logic flaws before deployment. Avg: ~1.1M tokens/day.

3. Content Generator Agent — Auto-generates social posts for the Pulse Protocol social graph (leaderboards, achievements, game tips) in 4 languages (EN, ID, ZH, JP). Runs hourly batch jobs. Avg: ~800K tokens/day.

4. Player Predictor Agent — Fetches on-chain player activity from Arweave GraphQL and uses AI to predict churn risk, engagement trajectory, and personalized retention strategies. Runs every 6h for 200+ active players. Avg: ~1.5M tokens/day.

Total token consumption: ~4.8M tokens/day across a team of 20+ developers and active players.

We currently use Claude Code + Cursor as our primary coding environment, with MiMo as our preferred reasoning model due to its superior cost-efficiency vs Claude/GPT for chain-of-thought tasks. Monthly API spending across providers: $180–$320/month. MiMo's pricing structure makes it 35–40% more cost-efficient for our reasoning-heavy workloads.

GitHub: https://github.com/AnwarSup/ao-mind
Platform: AO Computer (Arweave) | Language: JavaScript (ES Modules) | License: MIT
```
